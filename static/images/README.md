# Profile Image

Place your profile photo here as:

    static/images/profile.jpg

Accepted formats: JPG · PNG · WEBP
Recommended size : square crop, minimum 400 × 400 px

After adding the file, commit and push:

    git add static/images/profile.jpg
    git commit -m "feat: add profile photo"
    git push

The image will appear automatically on the About page at /about/
